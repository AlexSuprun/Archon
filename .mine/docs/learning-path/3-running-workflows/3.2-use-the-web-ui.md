# 3.2 Use the Web UI

What this answers: which HTTP routes drive the Web UI, how live updates are streamed, and where artifacts and env vars are managed.

## Start the UI

```
archon serve              # downloads web dist on first run, default port 3090
archon serve --port 4000
archon serve --download-only
```

In a worktree, `bun dev` auto-allocates a port in `3190–4089` based on a hash of the worktree path. Override with `PORT=...`.

## REST routes

### Workflows

| Method | Path | Purpose |
|---|---|---|
| GET | `/api/workflows` | List discovered workflows (optional `?cwd=`) |
| GET | `/api/workflows/{name}` | Fetch one workflow |
| PUT | `/api/workflows/{name}` | Create or update a workflow YAML (validates first) |
| DELETE | `/api/workflows/{name}` | Delete a user-defined workflow (bundled cannot be deleted) |
| POST | `/api/workflows/validate` | Validate a definition in-memory, no save |
| POST | `/api/workflows/{name}/run` | Start a run |
| GET | `/api/commands` | List bundled + project commands |

### Workflow runs

| Method | Path | Purpose |
|---|---|---|
| GET | `/api/workflows/runs` | List runs |
| GET | `/api/workflows/runs/{runId}` | Fetch one run |
| GET | `/api/workflows/runs/by-worker/{platformId}` | Runs owned by a platform worker |
| GET | `/api/dashboard/runs` | Dashboard summary |
| POST | `/api/workflows/runs/{runId}/cancel` | Cancel a live run |
| POST | `/api/workflows/runs/{runId}/resume` | Mark for resume on next dispatch |
| POST | `/api/workflows/runs/{runId}/abandon` | Mark non-terminal as cancelled |
| POST | `/api/workflows/runs/{runId}/approve` | Approve a paused run |
| POST | `/api/workflows/runs/{runId}/reject` | Reject a paused run |
| DELETE | `/api/workflows/runs/{runId}` | Delete a terminal run and its events |

### System

| Method | Path | Purpose |
|---|---|---|
| GET | `/api/health` | Health + adapter status |

### Artifacts

`GET /api/artifacts/:runId/*`

- Wildcard captures filename relative to the run's artifacts dir.
- `.md` files served as `text/markdown`; everything else `text/plain`.
- Path traversal blocked: any `..` segment, leading `/`, or null byte returns 400.
- Resolved path must stay inside the run dir; otherwise 400.
- Returns 404 if run, codebase, or file is missing.

## SSE streaming

Two endpoints:

| Path | Purpose |
|---|---|
| `GET /api/stream/__dashboard__` | Multiplexed: every workflow event for every run |
| `GET /api/stream/:conversationId` | Per-conversation events |

Wire format: standard `EventSource` SSE. Each frame is a JSON object in `data:`. The first frame after connect is always:

```
{ "type": "heartbeat", "timestamp": <ms> }
```

Heartbeat repeats every 30s while the connection is open. Other frames are workflow events (see 3.5 for the event type list) and platform messages.

The connection stays open until the client aborts; the server logs `sse_client_disconnected` on close.

## Web UI surface

| Area | Backed by |
|---|---|
| Run list, status badges | `GET /api/workflows/runs`, `/api/dashboard/runs` |
| Live DAG / node progress | `/api/stream/__dashboard__` (dashboard) or `/api/stream/:conversationId` |
| Approve / reject buttons | `POST .../approve`, `POST .../reject` |
| Resume / abandon / cancel / delete | `POST .../resume`, `.../abandon`, `.../cancel`, `DELETE .../{runId}` |
| Artifacts browser | `GET /api/artifacts/{runId}/*` |
| Env var manager | `GET/PUT /api/codebases/{id}/env`, `DELETE .../env/{key}` |
| Workflow editor + validator | `GET/PUT/DELETE /api/workflows/{name}`, `POST /api/workflows/validate` |

`interactive: true` workflows must run on the web surface to use approval gates (foreground execution required).

## Type generation

Frontend types are generated from `/api/openapi.json`:

```
bun --filter @archon/web generate:types
```

Run with the server live at port 3090.
